# بانک ایده‌های ParallelType (زنده — ورودی جلسات شورا)

> هر چیزی که «می‌شود انجام داد» — بدون فیلتر زمان/نیرو. شورا از این بانک برای فازبندی موج‌های بعدی برداشت می‌کند؛ هیچ آیتمی رد نهایی نیست مگر صریحاً در «ممنوع/رد‌شده».
> قواعد ایستاده‌ای که بعضی ایده‌ها به آن برخورد می‌کنند: UI فقط انگلیسی؛ بدون سرور/اکانت اینترنتی؛ مسابقه آنلاین هرگز آمار محلی نمی‌نویسد.

## ۱. تایپ و محتوا
- حالت «جملات»: تایپ متون ادبیات فارسی (حافظ/سعدی/شعر معاصر) با نقل‌قول‌های قابل‌گسترش
- حالت «کد»: تایپ اسنیپت‌های واقعی (Rust/TS/Python) با syntax نصفه‌ونیمه و دریل RTL/LTR مخلوط
- حالت «املا» (dictation): TTS جمله را می‌گوید، کاربر می‌نویسد — ادغام با hear-it موجود
- دریل نیم‌فاصله و علائم فارسی (، ؛ ؟ «») — دو دریل اختصاصی فارسی
- دریل «کلمات هم‌خانواده» و «ارگ/تیپست» (بسامد پالس روی کلیدهای ضعیف)
- استخر متون قابل‌گسترش از فایل کاربر (فولدر texts/ خوانده‌شود)
- «تمرین هدف‌مند per-key» عمیق‌تر: زنجیره دریل تا تسلط (keybr فارسی فعلی + معیار تسلط)

## ۲. آمار و تحلیل
- heatmap کلیدها در گذر زمان (هفته به هفته) روی صفحه اکانت
- گزارش هفتگی/ماهانه + هدف‌گذاری (target WPM هفتگی با استریک)
- نمودار روند هر بازی و هر کلید (گیت: خواندن از استورها)
- import نتایج از monkeytype وب (سازگاری JSON)
- خروجی «گزارش استاتیک HTML» از کل آمار (بدون سرور — فایل تک‌صفحه‌ای)
- sync پروفایل بین دستگاه‌های خود کاربر از طریق LAN (بدون ابر)

## ۳. موج آنلاین / LAN
- **تورنمنت ۳+ نفره**: هاست N کلاینت را رله کند؛ براکت حذفی — تغییر اصلی pipe (فقط یک اتصال فعلاً)
- **تماشاگر زنده**: دستگاه سوم مسابقه دو نفر را real-time تماشا کند (همان snapshot stream، فقط رندر)
- **replay مسابقه**: ضبط تایم‌لاین ورودی → بازپخش ghost حریف یا خودت
- **ghost racing عمومی**: رقابت با ghost ران قبلی خودت در همه بازی‌های امتیازی
- **چت متنی بین مسابقه‌ها** روی همان pipe (پیام‌های کوتاه، سقف‌دار)
- **duel روی متن سفارشی**: هر دو نفر همان متن سفارشی کاربر را بزنند
- **رله تیمی**: دو بازیکن یک مسابقه را کلمه‌به‌کلمه تقسیم کنند
- **لیدربورد LAN**: استور مداوم رکوردهای مهمان‌ها روی هاست
- گانتلت روزانه به‌اشتراک‌گذاری‌شده: دوستان همان seed روزانه را بزنند و مقایسه شوند

## ۴. بازی‌ها
- ایده‌های بازی تازه (مثلاً tower-defense تایپی دو‌نفره هم‌زمان، word race دو سر زمین)
- preset سختی per-game قابل‌صدور/ورود (چالش دوستان)
- تماشای آنلاین بازی‌های امتیازی (همان spectator)
- جدول «قهرمانان» per-game روی هاست LAN

## ۵. پلتفرم و انتشار
- بیلد portable zip (بدون نصب) کنار NSIS
- MSIX/Store submission و manifestهای winget/scoop
- احیای بیلد لینوکس (pkg.tar.zst قدیمی) + ARM64 ویندوز
- کانال آپدیت (stable/beta) — latest.json دو نسخه‌ای
- اتوماسیون ریلیز کامل: tag → بیلد → امضا → Release سه‌فایلی (حذف گام دستی فعلی)
- CI متا: تست دودِ نصب‌کننده (سایلنت نصب روی runner + اجرا)

## ۶. UX و پولیش ظاهری
- **ویرایشگر تم** کاربر + صادرات/ورود تم (JSON)
- پک‌های صدا (چند scheme کلیک/خطا قابل‌تعویض)
- پاس RTL سراسری نهایی (هر صفحه یک‌بار با چشم تازه)
- accessibility: high-contrast، keyboard-only nav کامل، aria sweep
- onboarding اولین اجرا (راهنمای ۵ مرحله‌ای تعاملی)
- شخصی‌سازی چیدمان صفحه اصلی (کاربر کارت‌ها را بچیند)
- انیمیشن‌های reduced-motion-friendly برای پاداش‌ها/پروازها

## ۷. ساختار و مهندسی
- **پاکسازی بدهی strictness** (~۱۰۰۰ خطای tsc لینوکس) — موج مستقل
- e2e harness واقعی: دومین peer اسکریپت‌شده در تست Rust (TCP loopback کامل — join→start→race→verdict)
- جداسازی loded-up monorepo: حذف backend/packages بلااستفاده از workspace (سبک‌سازی install)
- لاگ فایل‌محور برای دیباگ کاربران (بدون telemetry)
- پروفایل startup (زمان بوت + مصرف حافظه) و بودجه‌بندی آن
- بازنگری ساختار پوشه‌ها: جدا کردن «موتورهای بازی» از «صفحات» به‌صورت یکنواخت

## ۸. بازی‌گامیفیکیشن
- سیستم نشان/مدال (achievements) با معیارهای خالص
- استریک چندبعدی (روزانه + هفتگی + per-game)
- «streamer mode»: فونت غول‌آسا + overlay سبک OBS
- challenge دیلی با seed قابل‌اشتراک (کد چالش برای دوستان)

## ۹. رد‌شده/ممنوع (تا رأی جدید شورا)
- سرور/اکانت اینترنتی، کلاد sync، telemetry آنلاین — قاعده LAN-only و آفلاین‌محوری
- UI فارسی — قاعده «UI فقط انگلیسی» (در صورت رأی جدید شورا، i18n کامل UI با toggle)
- sync آپ‌استریم monkeytype — واگرایی عمدی
