# تحقیق: بهترین روش‌ها و قابلیت‌های آموزش تایپ در جهان (B11-پژوهش)

**تاریخ:** 2026-10-28 | **روش:** جستجوی وب روی ابزارهای شاخص (Keybr، TypingClub، Typing.com، Nitro Type، TypeRacer، ZType، Agile Fingers، The Typing Practice، TypeThrive) + منابع پژوهشی (procedural memory، passive haptic training) + تجربه‌ی جوامع کاربری (r/typing و…).

## ۱. یافته‌های کلیدی از اکوسیستم جهانی

| ابزار | ایده‌ی برگ برده | درس برای ParallelType |
|---|---|---|
| **Keybr** | الگوریتم تطبیقی حرف‌به‌حرف: شروع با چند حرف، قفل‌گشایی حرف بعدی فقط پس از عبور آستانه‌ی سرعت/دقت، تولید متنِ مغرض‌به‌سوی حروف ضعیف | قوی‌ترین ایده‌ی آموزشی دنیا — قابل پیاده‌سازی کاملاً آفلاین |
| **TypingClub / Typing.com** | دوره‌ی ساخت‌یافته‌ی مرحله‌به‌مرحله (home row → سطرها → کلمات → جملات)، ۶۵۰+ بازی، درس‌های زوج‌کلیدی | ساختار درس‌محور برای تازه‌کارها |
| **The Typing Practice** | «Practice Any Keys»: دریل دستی روی هر زیرمجموعه‌ی کلید (یک سطر، یک دست، اعداد) | مکمل ساده برای funboxهای فورک |
| **Nitro Type / TypeRacer / ZType** | بازی‌مسابقه‌ای (ماشین، چندنفره، تیراندازی به کلمات) | نگه‌داشتن انگیزه — به‌عنوان «تمرین» روی تکنین درست، نه آموزش اولیه |
| **Agile Fingers / Typing.com** | کیبورد مجازی با راهنمای انگشت + نمودار مالکیت هر انگشت | بازخورد فوری برای جلوگیری از نگاه‌کردن به دست |
| **Typesy / پژوهش‌ها** | حافظه‌ی رویه‌ای (procedural memory) + تمرین کوتاه روزانه + haptic feedback | توجیه علمی تمرین کوتاهِ منظم |

## ۲. اصول علمی مستخرج

1. **دقت قبل از سرعت:** تا دقت ≥۹۵٪ تثبیت نشده، سرعت را بالا نبرید — سرعت خودش می‌آید (اجماع همه‌ی منابع).
2. **حافظه‌ی رویه‌ای:** مهارت تایپ از سیستم حافظه‌ی رویه‌ای مغز می‌آید → تمرین کوتاهِ روزانه بهتر از جلسات طولانی.
3. **بازخورد فوری:** خطا باید همان لحظه مشخص شود (کاراکتر اشتباه in-place) — هسته‌ی Monkeytype ✓ موجود.
4. **تمرین عامدانه:** هر سشن روی نقطه‌ضعف مشخص (زوج کلیدی/سطر) — نه تایپ تصادفی.

## ۳. پیشنهاد قابلیت‌ها برای ParallelType (اولویت‌بندی‌شده، همه آفلاین)

### P0 — هسته‌ی آموزشی (بیشترین اثر، کم‌هزینه‌ترین)
| قابلیت | توضیح | منبع الهام |
|---|---|---|
| **حالت «آموزش تدریجی» (Keybr-style)** | موتور تولید کلمه‌ی جدید: شروع با home row، قفل‌گشایی حرف بعدی پس از رسیدن به آستانه‌ی سرعت/دقت روی حروف فعلی؛ ردیابی سرعت و خطای هر کلید در IndexedDB؛ متن تولیدی مغرض‌به‌سوی کلیدهای ضعیف | Keybr |
| **دریل زوج‌کلیدی/سطری** | funbox یا حالت تمرین: «فقط sطر پایین با d,j» — با فیلتر ژنراتور کلمات روی زیرمجموعه‌ی حروف | The Typing Practice، Typing.com lessons |
| **آمار حرارتی کلیدها (key heat map)** | صفحه‌ای که سرعت/خطای هر کلید را رنگی نشان می‌دهد — خوراک داده برای دریل ضعیف‌ها | Keybr stats |

### P1 — راهنمایی و انگیزه
| قابلیت | توضیح | منبع الهام |
|---|---|---|
| **کیبورد مجازی با هایلایت انگشت** | نمایش کلید بعدی روی کیبورد مجازی + رنگ انگشت مربوطه (قابل خاموش‌کردن) | Agile Fingers، Typing.com |
| **دریل هوشمند «کلیدهای مشکل‌دار من»** | دکمه‌ای که از تاریخچه‌ی IndexedDB یک تمرین ۳۰ ثانیه‌ای از پرخطاترین کلیدهای کاربر می‌سازد | The Typing Practice |
| **زنجیره‌ی روزهای تمرین (streak محلی)** | بدون سرور: شمارش روزهای متوالی + نمودار فعالیت (calendars موجود در snapshot محلی) | TypingClub |

### P2 — انگیزه و گیمیفیکیشن (بعد از تثبیت هسته)
| قابلیت | توضیح | منبع الهام |
|---|---|---|
| **بازی ZType-style آفلاین** | کلمات می‌آیند، با تایپ نابود می‌شوند — از کلمات همان دیتاست | ZType |
| **مسابقه با رکورد خودتان (ghost)** | caret شبح‌وار که مسیر بهترین تست قبلی خودتان را تکرار می‌کند | TypeRacer (نسخه‌ی تک‌نفره) |
| **دستاوردها/نشان‌های محلی** | نشان برای streak، دقت ۱۰۰٪، عبور از آستانه‌های سرعت — همه محلی | Nitro Type |

### غیرپیشنهادی (با دلیل)
- لیدربورد آنلاین — نیازمند سرور؛ با فلسفه‌ی آفلاین فعلی ناسازگار (B7/self-host بعدها).
- دوره‌های ویدیویی سنگین — حجم بالا، ارزش افزوده کم نسبت به حالت تدریجی.

## ۴. نکته‌ی مهم برای فارسی

- الگوریتم تطبیقی باید روی **حروف چسبنده‌ی فارسی** هم کار کند (واحد شمارش = کاراکتر پس از شکل‌دهی، همان‌طور که monkeytype شمارش می‌کند).
- برای فارسی، ترتیب قفل‌گشایی بهتر است از «کلیدهای پرتکرار فارسی» شروع شود نه home row لاتین (دیتاست persian موجود قابل استفاده است).
