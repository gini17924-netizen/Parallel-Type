> ورودی‌ها: IDEAS_BACKLOG §۶ (۷ کاندیدا برای ۵ اسلات فاز ۹۲-۹۶)، قواعد ایستادهٔ بانک ایده‌ها
> (UI فقط انگلیسی؛ بدون سرور/اکانت؛ مسابقهٔ آنلاین هرگز آمار محلی نمی‌نویسد)، درس‌های KI

## ۱. جدول audit صفحات (۴۴ مسیر، گروه‌بندی‌شده)

| گروه (مسیرها) | یافتهٔ audit — منوها/دکمه‌ها/عناصر |
| --- | --- |
| **تایپ اصلی** (`/`, `/home`) | گرید واژه‌ها per-word RTL (فاز ۶۷) درست است؛ نقص: اعداد تایمر/WPM در حاشیهٔ متن فارسی LTR رندر می‌شوند؛ خط «انتظار تایپ» با نقل‌قول فارسی علائم پایانی را سر خط می‌اندازد |
| **آموزش** (`/learn`, `/keybr`, `/drills`, `/sections/$id`) | دریل کد: کامنت فارسی داخل اسنیپت LTR — جهت هر خط صحیح است ولی «…» وسط جملهٔ فارسی جا جابه‌جا می‌شود؛ drills کارت‌های جهت‌خنثی دارند (سلامت)؛ عنوان‌های فارسی داخل دکمه‌های انگلیسی تراز راست/چپ مخلوط می‌سازند |
| **هاب بازی‌ها** (`/games`, ۲۳ مسیر بازی) | کارت‌های بازی با اعداد فارسی/لاتین مخلوط — بی‌مسئله؛ مودال‌های بازی (راهنما/نتیجه) فقط انگلیسی — قاعده رعایت است؛ نتیجهٔ گانتلت: نام‌های فارسی بازیکنان در جدول تراز می‌شکنند |
| **آنلاین** (`/games/online`) | چت با متن فارسی: ورودی جهت‌خنثی است ولی لاگ چت جملهٔ فارسی را چپ‌چین می‌چیند (باید per-message dir بخواند)؛ لابی: جدول قهرمانان با نام فارسی — همان تراز شکسته |
| **آمار** (`/account`, `/wrapped`, `/profile`, `/profile/$uidOrName`, `/friends`) | wrapped: جمله‌های فارسی با اعداد — نقطهٔ داغ اعداد؛ نمودارها جهت‌خنثی (سلامت)؛ friends: لیست نام‌ها بی‌مسئله |
| **تنظیمات و حساب** (`/settings`, `/account-settings`, `/login`) | تمام برچسب‌ها انگلیسی — قاعده رعایت؛ بخش صدا: scheme فعلی بدون پیش‌شنود؛ بخش تم: بدون ویرایشگر (اسلات ۹۲) |
| **پوسته** (`/about`, `/leaderboards`, `/404`, loading/error) | about: فارسی و انگلیسی مخلوط در پاراگراف‌های جدا — سلامت؛ 404/loading انگلیسی — سلامت |

**نقاط داغ RTL (ورودی گیت رگرسیون فاز ۹۴):** گرید واژه‌های تایپ، دریل کد (کامنت فارسی)، دریل
نیم‌فاصله/علائم، چت لابی، جدول قهرمانان، wrapped (اعداد)، لیدربورد (نام فارسی).

### ۱.ب. سرنوشت نقاط داغ در فاز ۹۴ (جدول audit به‌روزشده — گیت بریف)

| نقطهٔ داغ | فیکس/تصمیم (فاز ۹۴) |
| --- | --- |
| چت لابی (per-message dir) | **فیکس شد**: span متن هر پیام `dir="auto"` گرفت (متن فارسی راست‌به‌چپ می‌چیند و رگه‌های لاتین مثل «gg» دیگر جا نمی‌پرند) + spec رگرسیون (`chat-message-text`) |
| جدول قهرمانان (نام فارسی) | **فیکس شد**: span نام `dir="auto"` + spec رگرسیون (`champion-name`) |
| جدول مقایسهٔ گانتلت (نام فارسی) | **فیکس شد**: span نام `dir="auto"` + spec رگرسیون (`board-name` — جدول چندردیفی: همهٔ ردیف‌ها dir=auto و ردیف فارسی حاضر) |
| گرید واژه‌های تایپ | **از قبل پوشیده**: مکانیزم per-word RTL فاز ۶۷ (isWordRightToLeft با حذف علائم از سر و ته واژه + کش) و spec پین‌شدهٔ کد-دریل — بدون تغییر |
| دریل کد (کامنت فارسی، «…») | **از قبل پوشیده**: مسیر واژه‌ها از همان مکانیزم می‌گذرد؛ علائم سر/ته واژه در تشخیص جهت حذف می‌شوند — بدون تغییر |
| wrapped (اعداد در جملهٔ فارسی) | **تصمیم**: wrapped در کد کاملاً انگلیسی است (قاعدهٔ UI-انگلیسی) — هیچ تعامل bidi وجود ندارد؛ یافتهٔ audit گمانه‌زنی بود، فیکس ندارد |
| لیدربورد (نام فارسی) | **تصمیم**: لیدربورد/جستجوی پروفایل سرور-گیت‌اند و در دسکتاپ فورک دادهٔ واقعی ندارند؛ اگر روزی پر شدند، همان الگوی `dir="auto"` روی سلول نام اعمال می‌شود — فیکس اکنون ندارد |

## ۳. بریف‌های نهایی (agent-executable)

### فاز ۹۲ — ویرایشگر تم کاربر + صادرات/ورود
- **هدف:** کاربر تم خودش را بسازد، ذخیره کند، بین دستگاه‌ها با فایل جابه‌جا کند.
- **فایل‌ها:** `utils/themes/custom-themes.ts` (استور مستقل `mtDesktopCustomThemes` — الگوی independent-store؛ zod روی ThemeSchema موجود)، بخش تازه در Settings (فرم رنگ‌ها با picker روی همهٔ ColorNameهای ThemeSchema — `updateThemeColor` موجود مصرف می‌شود)، صادرات/ورود JSON با الگوی `difficulty-preset` فاز ۸۶ (validate → اعمال؛ فایل متخاصم نمی‌تواند مقدار قاچاق کند).
- **گیت:** spec — build/round-trip validate، رد variant/version/name خالی، cap تعداد تم کاربر، اعمال تم روی CSS vars؛ tsc/oxlint صفر + verify CI سبز.
- **پایان:** «export تم من → import روی دستگاه دوم → همان رنگ‌ها».

### فاز ۹۳ — پک‌های صدا + پیش‌شنود
- **هدف:** تعویض scheme کلیک/خطا با شنیدنِ قبل از انتخاب.
- **فایل‌ها:** توسعهٔ `constants/sounds.ts` (پک = جفت کلیک+خطای هم‌خانواده با id)؛ بخش صدا در Settings: لیست پک‌ها + دکمهٔ پیش‌شنود (play روی click — unlock AudioContext روی همان gesture) + انتخاب پایدار در کانفیگ موجود.
- **گیت:** spec — پک‌ها شناسنامهٔ کامل دارند (کلیک+خطا)، انتخاب در کانفیگ پایدار می‌ماند، پیش‌شنود از state خارج از تایپ صدا می‌دهد؛ گیت CI.
- **پایان:** کاربر پک را می‌شنود، عوض می‌کند و در تایپ بعدی همان را می‌شنود.

### فاز ۹۴ — پاس RTL (محتوای فارسی در UI انگلیسی)
- **هدف:** حذف نقص‌های جهت در نقاط داغ + گیت رگرسیون دائمی.
- **فایل‌ها:** چک‌لیست هر نقطهٔ داغ §۱ → فیکس‌ها (اعداد در جملهٔ فارسی با LTR isolate، علائم پایانی، تراز جدول‌ها با نام فارسی، per-message dir در چت لابی)؛ spec رگرسیون روی نقاط داغ ثابت (گرید واژه‌ها، دریل کد، نیم‌فاصله، چت).
- **گیت:** spec رگرسیون + جدول audit به‌روزشده در همین سند (ستونهٔ «فیکس شد»)؛ گیت CI.
- **پایان:** هیچ نقطهٔ داغی بدون فیکس یا تصمیم ثبت‌شده نماند.

### فاز ۹۵ — accessibility
- **هدف:** سه لایهٔ ماشین‌پذیر: گیت استاتیک، حرکت‌کاهی، کنتراست.
- **فایل‌ها:** (الف) فعال‌سازی زیرمجموعهٔ قواعد jsx-a11y در oxlint روی کل درخت + رفع یافته‌ها (گیت دائمی)؛ (ب) `prefers-reduced-motion` روی انیمیشن‌های پاداش/پرواز بازی‌ها (کاندیدای ادغام‌شده)؛ (ج) تم مقایسه‌ای high-contrast در همان رجیستری تم؛ (د) focus ring و Esc روی همهٔ مودال‌ها + skip link.
- **گیت:** oxlint با قواعد تازه صفر روی کل درخت؛ spec مودال‌ها برای Esc/focus؛ گیت CI.
- **پایان:** پیمایش فقط‌باکیبورد کامل روی صفحات اصلی + گیت دائمی.

### فاز ۹۶ — onboarding + چیدمان شخصی خانه
- **هدف:** اولین اجرا گرم؛ کاربر فعلی مزاحم نشود.
- **فایل‌ها:** `utils/onboarding/` — ماشین‌حالت ۵ مرحله‌ای (خوش‌آمد → اولین تایپ → بازی‌ها → LAN → تنظیمات) با skip هر مرحله و store مستقل `mtDesktopOnboarding`؛ صفحهٔ خانه: ترتیب/نمایان‌بودن کارت‌ها با store مستقل (`mtDesktopHomeLayout`) — جابه‌جایی با دکمه‌های بالا/پایین، نه درگ‌و دراپ.
- **گیت:** spec ماشین‌حالت (ترتیب مراحل، skip، عدم نمایش بعد از پایان، رفتار reset) + spec پایداری چیدمان؛ گیت CI.
- **پایان:** کاربر تازه هر ۵ مرحله را یک‌بار می‌بیند؛ کاربر فعلی هرگز نمی‌بیند؛ چیدمان خانه ماندگار است.

## ۴. رأی رئیس و ریسک باقی‌مانده
- تخصیص و ترتیب ۹۲→۹۶ بدون جابه‌جایی تأیید شد؛ هر فاز با گیت ماشین‌پذیر خودش بسته می‌شود.
- ریسک: audit RTL از روی کد انجام شده (نه رندر) — چک‌لیست ثبت‌شده تا بازبینی رندری بعدی (در صورت نیاز) روی همان برود؛ مسیر آپدیت بتا فقط یک‌بار در CI دیده شده — بی‌اثر برای این بلوک.
- فرض مؤثر: قواعد ایستاده بدون رأی تازهٔ شورا پابرجاست.
