# شورای Online Games موج دوم — آنلاین‌سازی همه بازی‌های دارای پتانسیل دو نفره — 2026-11-08

## قرارهای مالک (این جلسه)
1. همه بازی‌هایی که پتانسیل بازی دو نفره دارند پیدا شوند، برای هرکدام برنامه ساخته شود و فازبندی کامل چیده شود.
2. **فازها به هیچ دلیلی کم نباشند** — هر تعداد فاز که لازم است چیده شود.
3. قواعد ماندگار: متن UI فقط انگلیسی؛ هیچ‌چیز آنلاین persist نمی‌شود؛ مسابقه آنلاین هرگز آمار محلی/گانتلت/PB نمی‌نویسد؛ فرانت هرگز socket نمی‌زند (فقط فرمان‌های `lan_*` و eventهای `lan://`)؛ بازی‌های آنلاین هرگز results/PB اصلی را نمی‌نویسند.

## میراث قابل استفاده (از طرح LAN ۶/۶ بسته‌شده)
- لوله Rust + discovery + لابی (`/games/online`) + hardening پنج‌گانه — همه بازی‌های بعدی روی همین pipe می‌نشینند.
- **الگوی bot-duel = قالب همه**: arm مسابقه (`states/lan-match.ts`)، progress رله، فاز awaiting، داوری finishMs، margin، rematch، void روی قطع.
- `createSeededRng` (همان LCG موتورها، از گانتلت KI-40) — seed مشترک مسابقه.
- بررسی کد (این جلسه): **هیچ موتوری Math.random ندارد** — همه خالص با rng تزریقی؛ sprint و maze-runner از قبل rng تزریقی کامل دارند؛ ghost-gp پیمانکار منحنی (`createCurvePacer`) آماده دارد.

## چهار الگوی فنی

- **الگوی R (مسابقه/RemotePacer)**: هر دو همان استریم seeded را تایپ می‌کنند؛ پیشرفت حریف زنده به‌صورت pacer تزریقی رندر می‌شود؛ برنده = اولین crossing؛ حریفِ تمام‌نشده `finished(null)` می‌فرستد. قالب: bot-duel.
- **الگوی S (امتیاز-مسابقه)**: هر دو همان seed را بازی می‌کنند؛ امتیاز/وضعیت زنده رله و در HUD حریف رندر می‌شود؛ پایان با تایمر/اتمام مشترک؛ برنده = امتیاز بالاتر (tiebreak: زمان رسیدن به امتیاز). نیازمند: seed در `start` + encoder/decoder progress per-game.
- **الگوی H (hot-seat → LAN)**: split-duel — هر بازیکن نیمه اختصاصی خودش را با کیبورد کامل خودش می‌زند (تفکیک code چپ/راست فقط در حالت hot-seat می‌ماند)؛ هر سمت استریم خودش را رله می‌کند؛ برنده = اولین سمتی که استریمش تمام شود.
- **الگوی V (versus واقعی با state-sync)**: type-pong — یک توپ مشترک؛ **هاست authoritative** شبیه‌سازی می‌کند و snapshot توپ را می‌فرستد؛ کلاینت فقط ورودی پدالش را می‌فرستد و پدال حریف را با interpolation می‌کشد. تنها بازی که پروتکل state-sync می‌خواهد — بلوک مستقل در انتهای فازبندی.

## معماری — قرارداد `LanPlayable` (زیرساخت مشترک)

```ts
// utils/games/lan-registry.ts — قرارداد نازک؛ هر بازی یک ثبت
export type LanStartPayload = {
  gameId: LanGameId;
  /** seed مشترک createSeededRng — استریم/بورد/چارت یکسان برای هر دو */
  seed: number;
  /** پارامترهای per-game (طول مسابقه، tier، ...) — اعتبارسنجی در رجیستری */
  params: Record<string, unknown>;
  peerName: string;
};
export type LanPlayable = {
  gameId: LanGameId;
  route: string;           // هر دو بازیکن به این مسیر می‌روند
  label: string;           // برچسب انتخابگر لابی (انگلیسی)
  icon: string;            // FA5
  buildStart(params): LanStartPayload;      // سمت هاست
  validateParams(params): boolean;          // قبل از arm — هر دو سمت
  encodeProgress(state): Record<string, unknown>; // فشرده، سقف 64KB
  decodeProgress(payload): RemoteState | undefined;
};
```

- `states/lan-match.ts` تعمیم می‌یابد: `armLanMatch` payload عمومی (gameId+seed+params)؛ `handleLanPeerMessage` به‌جای hard-code «bot-duel» از رجیستری route می‌خواند؛ progress با پاکت `{type:"progress", gameId, state}` رد و بدل می‌شود.
- لابی: **انتخابگر بازی** — کارت‌های بازی‌های آنلاین‌شده از رجیستری (روشن) + بازی‌های آینده (خاکستری «soon»)؛ تنظیمات per-game (طول مسابقه و…) زیر انتخابگر.
- صفحه هر بازی: از `getLanMatch()` وضعیت را می‌خواند؛ adapter حریف (مثل RemotePacer) + HUD حریف + داوری per-game + rematch/void — همه مطابق قالب bot-duel.
- هر فاز گیت کامل می‌گیرد (vitest کل + tsc + oxlint ریشه + oxfmt + کامیت + تیک سند) — همان قاعده همیشگی.

## ریسک‌های ثبت‌شده
- **skew شروع** در حد یک RTT — الگوی bot-duel (countdown یکسان بعد از رسیدن start)؛ داوری با اعداد فریم‌های هم‌تراز.
- **seed leakage** = بازیکنان همان استریم را می‌بینند — هدف همین است (هم‌سطح گانتلت روزانه)؛ نه رقابت امنتی.
- **انفجار HUDها** — هر صفحه فقط یک پنل حریف اضافه می‌کند؛ KI-34 (خواندن inline سیگنال در JSX) در همه صفحات تازه چک اجباری.
- **type-pong (الگوی V)** — پیچیده‌ترین بلوک؛ اگر v1 ناپایدار بود، تعویقش فقط این بلوک را عقب می‌اندازد نه بقیه را.
- قطع وسط هر بازی → void بی‌ثبت (قالب bot-duel فاز ۵) — همه بازی‌ها یکسان.
